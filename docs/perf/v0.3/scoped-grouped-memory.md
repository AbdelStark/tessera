# Scoped grouped checkpoint memory

RFC-0077 extends the protocol/1 checked physical fallback to canonical grouped
leaf sources. The CPU retains the resident planner as its first choice and the
resident witness as the differential oracle. If no resident candidate fits, it
tries a complete ungrouped physical candidate, then the existing public group
order. Each physical candidate must price every phase before P1. This leaves the
resident logical-cell floor unchanged and excludes protocol/2 grouping.

A scoped factory derives identities from the checked lowering, runtime, advice,
leaf and group layouts. It constructs selected integer source columns, affine
lookup leaves, forest shares and restricted split tables for the current group.
An empty group-variable set can require a whole source; its complete allocation
is charged. At P2b it regenerates original tensor polynomials, followed by
original forest polynomials, in natural order. The merge point and every original
opening obligation are unchanged. The selected grouping determines P1's complete
padding multiplicities and remains fixed for the proof.

The factory borrows the actual checkpoint-backed graph cache. The complete cache,
checkpoint construction and replay, gadget tile work, native leases and their
construction overlap remain additional owners. A candidate is bounded only when
those complete owners fit. This implementation does not establish constant memory
in context length or a single forward pass. Public group processing can regenerate
some gadget tiles repeatedly; P2 and P2b are protocol passes, not a measured count
of forward equivalents. Real-model regeneration time still needs measurement.

The composed bill includes public plan/layout construction and trial-plan overlap,
source conversion and copies, current lookup/forest kernels, earlier group proofs,
kept merge tables, the table batch, original P2b source/copy/folded state,
native/reduction windows, target transfer, P4/P5, weight work and all retained wire
packets. Checked sums price simultaneous owners; maxima price alternative phases.
Unknown owners, overflow, unaddressable buffers and insufficient complete allowance
refuse before P1. A source-only or message-only estimate cannot admit a proof.
Caller model storage, stack, allocator overhead and external transport/runtime
allocations retain their separate whole-process reporting obligations.

Derived secret buffers retain clearing owners across normal completion and
refusals. Test callback failures check exact typed memory codes and zero retained
allocations after release. That is allocation-lifetime evidence combined with the
buffer's clearing contract; the tests do not inspect freed memory.

The source and grouped-kernel controls compare canonical values, splits, original
polynomials, native consumers, transcript events and encoded messages against the
resident implementation. Whole CPU controls cover token-only, layer-only and mixed
groups, distinct real-layer classes, greedy continuation, uneven request slots,
padded request ordinals and padded layers, with Servable, affine and Minimal fixtures. They compare complete NI artifacts and
scalar/parallel Live wire messages, require independent NI and fresh Live acceptance,
assert exact tamper reasons, measure complete heap peaks against the selected plan,
and check the one-byte-under admission refusal. A structural control proves the
scoped route never invokes the complete ModelWitness constructor.

Run the focused whole CPU control with:

```sh
cargo test -p tessera-prover --lib --features test-rng,test-params \
  grouped_scoped_cpu_qualification_matches_resident_and_independently_verifies \
  --locked -- --test-threads=1
```

These synthetic fixtures use non-certifying test-small parameters. They do not
qualify a pretrained model, prove quantization fidelity, establish production
soundness targets or demonstrate whole-process time/memory. Actual 1B/8B acceptance
and fidelity remain under the real-model milestones. No frozen model attempt is
restarted or credited to this later implementation.

Window metadata uses a public term envelope for each native instance, checked
against actual literal instances. The root envelope covers all 960 supported
coefficient/upper/lower cases, including retained zero fallbacks. This replaces a
coarse aggregate-as-per-instance estimate; native construction, prepare, source
and field-work reservations remain additional.

The public chooser control observes every canonical grouped trial at a no-fit
boundary without overriding decisions. It also preserves fitting ungrouped
physical and resident precedence. Native/stage work dominates the examined
planning fixture, so it establishes no automatic grouped positive or memory-saving
claim. The complete grouped proof controls exercise the same production selector
and bound, with only public grouping and resident preference overridden in tests.

The concrete two-layer, three-token source control observed 9,340 gadget-tile
callbacks across its 17 grouping/cut variants, 541–554 per variant. Counting wraps
the actual canonical callback during each scoped grouped proof, including original
source regeneration when that merge mode requests it. It excludes resident-oracle
calls, native construction, cache construction and general scalar graph reads.
These counts measure fixture callback work; they are neither forward-equivalent
counts nor a real-model throughput result. Set `TESSERA_SCOPED_WORK_RECORD` to a
fresh output path when running the source transcript control to retain the counts.
