# Survey a topic

Output: `research/surveys/SUR-NNNN-<slug>.md`, shaped by the template (`research/templates/survey.md`), for one topic of [agenda.md](agenda.md). The identifier is the ledger's next survey counter.

1. **Frame.** Copy the topic's standing questions from the agenda. For each, name the cost-model or scoreboard term it touches and the RFC section that fixes today's answer (baseline.md §6 (`research/baseline.md#6-levers-which-technique-class-moves-which-term`) maps technique classes to terms). Done when every question has a term and an RFC anchor.
2. **Search, primary first.** For each question: ePrint and arXiv by keyword and by author, then the repositories, blogs and venues the agenda lists, starting from the topic's query seeds; the date range starts at the topic's last survey, or at 2023 when there is none. Search broad with `WebSearch`, then read the source itself with `WebFetch` (the paper, the README, the benchmark page); when a PDF will not fetch, use the arXiv HTML rendering or the author's page. Record the URL and the date checked for every source. Done when each question has three primary sources, or a sentence saying fewer exist and where you looked.
3. **Extract** one findings row per source: the mechanism in one sentence; the numbers with their hardware and evidence level; the term moved; applicability (`direct`, `adapt` or `none`, with the reason); caveats (trusted setup, not post-quantum, field, unmeasured, hidden assumptions). A benchmark nobody outside its vendor reproduced is a `claim`. Done when no cell of the table is empty.
4. **Synthesize.** Settled against contested. Where sources disagree, both numbers and why. Which RFC decision each finding confirms or contradicts, naming the "Alternatives Considered" item when there is one. Done when every finding is placed.
5. **Seed ideas.** One line per `direct` or `adapt` finding: mechanism, term, rough gain, first killer. A finding without a seed carries a sentence saying why. Done when the list is complete.
6. **Staleness triggers and references.** Name the events that would date the survey early. Write a bibliography entry for every source: alone, append it to `bibliography.md`; in a sweep, return it to the orchestrator, which merges all entries at the end. Report the numbers that change `landscape.md` the same way. Done when every key the survey cites resolves.

Depth: the survey is complete when a reader could decide from it alone which techniques deserve an idea note, not when a length is reached. Relentless on primary sources; frugal on prose.
